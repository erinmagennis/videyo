# Turn an AI-video workflow into a review-first local production system

**Date:** 2026-07-29  **Context:** Videyo kickoff after the Arkhai launch-film pilot

## The approach that worked

- Interview the operator from concrete failures, then convert each failure into a review, safety, or file-management requirement.
- Separate saved evidence from reusable defaults: retain everything locally, then promote lessons to video, client, content-type, or global scope during handoff.
- Make transitions, audio-to-picture timing, and neighboring-scene context first-class planning data rather than late post-production cleanup.
- Validate the system on different real workloads: generated marketing, long animated narrative, hour-long spoken content, and a speaker reel.
- Keep original media immutable and make all automatic edits reversible; gate spend, external sharing, and deletion.

## Judgment calls

- A local macOS system fits Erin better than account-based cloud sync because collaboration and phone review are not current needs.
- The first slice is an Arkhai review hub, not a universal editor, because it tests the highest-friction workflow with immediate evidence.
- A one-hour animated film remains the target, but it must be proved and produced in acts rather than one opaque run.

## Reusable rule

Before automating media production, put the goal, neighboring context, assets, prompts, transitions, timed audio, versions, costs, and independent critique in one reversible local review surface.
